# c2c-005 · 声音表情包工坊

Vue 3 + TypeScript + Vite 纯前端声音创作工具。支持最长 10 秒录音/导入、裁剪、声学特征情绪匹配、Canvas 封面、IndexedDB 本地作品集和系统文件分享。

## 封面气泡拖动与自动避让

- 气泡可直接拖动，也支持方向键微调（Shift 加速）；靠近标题或装饰波形、超出安全边距时实时标出冲突范围。
- 冲突时按「移动（原字号单行）→ 换行（原字号折行）→ 缩放（最多缩到 28px）」的可读性顺序比较候选，同一冲突至少给出两种可采用位置及位移/行数/字号代价，推荐项不是位移最小者而是可读损失最小者。
- 可拒绝建议自行调整、撤销（含 Ctrl/⌘+Z）；任何候选在返回前都重新过碰撞判定。无法容纳时给出需要高度与可用高度的量化原因，冲突未解决前不能保存，渲染器也会拒绝导出越界图。
- 布局以百分比与相对字号随作品持久化，重新打开作品或改变预览大小均不漂移；方形/竖版切换后按新比例重新计算。
- 旧作品缺少布局信息时保持原始封面：作品集与导出沿用原图，进入封面编辑后由用户选择「开始调整」或「保持原图」，未保存前可一键恢复旧版原图。

碰撞模型与长气泡、窄画面、大标题三个对照案例见 `docs/superpowers/specs/2026-10-07-bubble-collision-avoidance-design.md`。

## 架构

- `src/core`：作品模型、特征归一化、情绪规则与封面预设
- `src/ports`：录音、音频、Canvas、仓储与分享接口
- `src/adapters`：MediaRecorder、Web Audio、Canvas、IndexedDB、Web Share 实现
- `src/ui`：Vue 阶段式工作流和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

本地开发默认由 Vite 提供；Docker 部署访问 `http://localhost:8105`。浏览器录音在非 localhost 环境通常需要 HTTPS 和麦克风权限。

声音只保存在本机 IndexedDB，不会上传。生成的分享链接仅承载标题、情绪和封面配置，不包含原始音频；文件分享不受此限制。情绪识别是娱乐性启发式结果，不代表身份、性格或医学判断。
